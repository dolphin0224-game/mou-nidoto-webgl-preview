# Release 06 — 動作・音・時間送り・霧

確認リンク（公開後）: https://dolphin0224-game.github.io/mou-nidoto-webgl-preview/?v=studio-20260908-06

## 今回確認してほしいところ

1. 鳥居から村を歩き、左右に視点を振る。滝や祭り広場でも移動して、以前の引っかかりと比較する。
2. 祭り広場への出入りや地点移動を繰り返す。BGMは短く音量を落として切り替わり、異なる曲が重ならない。川・雨・虫・笛などの環境音はBGMと共存する。
3. 最初の深夜、笛吹きの行列で選択肢を選ぶ。その後は画面下の「少し、ここで待つ」から時間を進められる。選択の結果は残り、行列が終わって次の出来事へ進む。まだ選択していない場面では時間送りを止める。
4. 遠くの森や山に霧がかかることを確認する。森・滝・雨では濃さが変わり、夜や赤い月では空に合わせて色が変わる。

## Unityで霧を調整する

既存スカイドームの `TenkokuModule` にある `enableFog` と `fogDensity` が、URPの距離霧にも反映される。再生中に設定を変更して、Gameビューで確認できる。`fogDensity` は従来値0.55を基準に、場所・天候の濃さへ倍率として適用する。霧の色はドームの `colorFog` を基に昼夜・赤い月へ補正する。

雨や霧の粒子がタイトル画面などで停止した後、探索へ戻る際に描画も復帰する。宿や地下道など屋根の下では雨粒を抑え、屋外では再開する。元のシーン・地形・空の配置は再生成していない。再生中の一時変更は、停止時に元の設定へ戻る。恒久的に残したい調整は再生停止後に設定する。

## 軽量化の範囲

背景モデル・テクスチャ解像度・影の解像度・描画距離を削る変更ではなく、同じ草花の描画、画面外の人物更新、表情の検索を整理する。配信ファイルは可逆圧縮し、展開後の品質は維持する。初回ダウンロードや端末固有のGPU負荷までなくなることを保証するものではない。数値と検証範囲は `CHECKLIST.md` を参照。
