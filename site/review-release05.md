# 音声・死亡・回帰の確認

## プレイヤーとして試す

公開版は `?v=studio-20260908-05`。以前のセーブを残したい場合は、別のブラウザプロフィールで開始してください。

1. 初回の会話を聞く。台詞は話者ごとの合成音声で再生されます。Spaceで次へ進むと前の台詞は止まります。
2. スマホに届く通知には「グループ『五人で帰る』」または「個別」と相手の名前が出ます。通知またはPで該当する会話を開きます。
3. Mで地図を開く。地名を選ぶと調査項目が出ます。人物情報は見聞きしたものだけ、地下道は判明した後に表示します。
4. **1周目・開始から2時間以内に南東の祠へ近づく**と、確認用の時間加速が始まります。注意を促す会話の後、2日目22時へ進みます。
5. 化け物の襲撃後は自動的に、実際に見たカットシーンの映像が逆の順に流れます。音が加速し、異質な映像が短く混ざって、バスの到着地点へ戻ります。
6. 2周目では蒼が体調を崩し、蓮と澪が声を掛けます。会話が終わると、開始時刻・仲間の生存・探索用の姿勢に戻ります。日記に得た記憶は残ります。祠の確認用加速は2周目には繰り返しません。

時間加速は今回の演出確認用です。通常の探索を優先する際は、Unityの `NeverAgainReturn.shrinePreview` をオフにできます。周回の映像はその実行中に見た場面を一時的に保持するため、ページを再読み込みすると映像の履歴は消えます。

## 制作者として編集する

Unity **6000.5.0f1** で `Assets/_Project/MouNidoto/Scenes/MouNidoto.unity` を開きます。

カットシーン再生中にF8 →「現在のTimelineを開いて編集」。Voiceトラックのクリップ、音量、配置時刻、カメラ、字幕などを編集し、「編集を保存して次回にも反映」を押してください。Playを終了するだけでは編集内容は保存されません。音声の生成・ライセンス・各役の割り当ては `Tools/Voice/README.md` を参照してください。

今回は元の作業フォルダーにある未コミットの美術変更を保全し、別の作業フォルダーで制作しました。共同制作者の `f472222` の本編シーン・空・天候同期を取り込んでいます。本編シーンは再生成していません。

## レビューの観点

- 通知を見て、誰とのどの会話か迷わず開けるか。
- 声の印象が人物像に合うか。特に疑問・焦り・呼び止めの読み方。
- 襲撃と周回の因果が分かるか。戻った瞬間に「同じ到着なのに自分の体験が違う」と感じるか。
- 朝昼夕夜で空・影・顔の読め方が変わるか。地図の地名と現在地を判別できるか。

モデル固有の表情演技と全カットの演技の磨き込みは、今回の機能追加とは別に継続してレビューが必要です。動画リファレンスはログイン制限のため該当部分を実視聴できず、依頼文にある「短い映像の加速・音の緊迫・一気に帰還」という意図から構成しています。
